## 3. Навигация и таб-бар
**3 вкладки: Главная · Статистика · Счета** + кнопка «+». Настройки — не вкладка, а экран по шестерёнке.
Почему 3: отдельный экран «Операции» дублировал ленту Главной. Лента и поиск живут на Главной; когда появятся бюджеты/цели (§5), вопрос о 4-й вкладке решается заново.

Реализация (уже сделана, `App/ContentView.swift`) — **нативный `TabView` iOS 26**, свой бар не рисовать:
- `.tabBarMinimizeBehavior(.onScrollDown)` — при скролле вниз бар сворачивается до активной вкладки;
- сводка рядом со свёрнутым баром — `.tabViewBottomAccessory(isEnabled: isScrolled)` (`Views/Components/TabBarSummary.swift`), показывается только когда экран прокручен ниже 30 pt (`reportsScroll`);
- «+» — вкладка `AppTab.add` с `role: .search` (система рисует её отдельным стеклянным кругом справа); тап перехватывается в `tabSelection` и открывает шит новой операции с любой вкладки. Вкладка `.search` занята под «+», поэтому **поиск в таб-бар не переносить** — он живёт в шапке Главной (§4.1.4).
- Активная вкладка: иконка и подпись `accent` (через `.tint`).
- «+»: круг — системное стекло (залить его своим цветом нативно нельзя), плюс — `accent`. Свёрнутая вкладка — только иконка (поведение системы). Решения владельца 2026-10-11.

Содержимое сводки — две колонки «подпись над суммой» на всех вкладках: основная слева (крупная сумма `ink`), вторая справа (выравнивание вправо, сумма меньше, `ink2`). Длинные суммы ужимаются (до 0.7), а не обрезаются.
- Главная: «Сегодня / −3 320 ₽» + справа «Октябрь / −84 320 ₽». **В режиме поиска** с непустым запросом: «Найдено / 12» + справа «Расходы / −8 400 ₽» (расходы среди найденного).
- Статистика: «Октябрь / 84 320 ₽» + справа «В день / 10 540 ₽».
- Счета: «Всего на счетах / 286 420 ₽», одна колонка слева.

1. **Шапка:** выбор месяца «Все операции ⌄» / «Август ⌄» (34 bold, длинное — ужимается до 70%) + стеклянная капсула 44 pt с кнопками **поиск** (→ режим поиска, §4.1.4) и **настройки** (→ Настройки).
   - **Выбор месяца** (решения владельца, 2026-10-12) — системное меню (`Menu`), порядок фиксированный: «Все операции», разделитель, месяцы от текущего (ближе к пальцу) к ранним. Месяцы — от месяца первой операции до текущего, включая пустые; месяцы текущего года без года, прошлых — с годом («Декабрь 2025»). Галочка на выбранном пункте.
   - Два способа: **долгий тап → провести палец до месяца → отпустить**; или **тап → меню открыто → прокрутка свайпом → тап по месяцу**.
   - «Все операции» (по умолчанию) — бесконечная лента, hero — текущий месяц. Выбранный месяц (в т. ч. текущий) — в ленте только его дни, hero — его сводка. Фильтр месяца работает вместе с фильтром счёта; **поиск ищет по всей истории** (месяц на время поиска не действует). Сводка у таб-бара — всегда текущий месяц.

#### 4.1.4 Поиск на Главной (новое)
Ориентир — системный жест iOS «потянуть вниз → поиск» (Spotlight на домашнем экране, поиск в Почте/Заметках) + морфинг Liquid Glass iOS 26.

**Состояния:**
```
1. Обычное                 2. Тянем вниз (0…70 pt)        3. Поиск активен
Октябрь ⌄      (🔍 ⚙)      Окт…  (🔍━━━━━━━━━ )           (🔍 Категория, счёт… ⓧ) (✕)
[hero]                      [hero]                          [карусель счетов]
[карусель]                  …                               [результаты по дням]
[лента]                                                     ─── клавиатура ───
```
**Вход в поиск — два пути, итог одинаковый:**
- **Тап по лупе** в шапке.
- **Жест «потянуть вниз»** у верха ленты (оверскролл, только когда поиск не активен):
  - прогресс `p = clamp(оверскролл / 70 pt, 0…1)`;
  - пока тянем: стеклянная капсула лупы растягивается влево (ширина от 44 до полной ширины шапки пропорционально `p`), «Октябрь ⌄» и шестерёнка плавно гаснут (opacity `1 − p`);
  - при `p` = 1: лёгкий хаптик (`.sensoryFeedback(.impact(weight: .medium))`, один раз за жест) и лупа чуть «подпрыгивает» (scale 1.1) — сигнал «отпусти, будет поиск»;
  - отпустили при `p` = 1 → активация; отпустили раньше → пружиной обратно в обычное состояние.

**Активация** (spring ~0.35 с, damping 0.8): лупа морфится в строку поиска (`glassEffectID` в общем `GlassEffectContainer`), строка встаёт на место шапки; справа от неё — круглая стеклянная кнопка ✕ 44 pt; **поле сразу получает фокус — появляется клавиатура** (как в Spotlight: потянул — и сразу печатаешь). Hero-карточка уезжает вверх и гаснет (`.move(edge: .top)` + `.opacity`); карусель счетов остаётся и работает как дополнительный фильтр.

**Строка поиска:** высота 44, стекло, капсула; слева `magnifyingglass` `ink2`; поле 17, плейсхолдер «Категория, счёт, тег или заметка»; при непустом запросе справа — `xmark.circle.fill` `ink2` (очистить, фокус остаётся). Клавиатура: `.submitLabel(.search)`, автокоррекция выключена, автокапитализация выключена.

**Правила поиска** (в `HomeViewModel`, покрыть тестами):
- запрос обрезается по краям; регистр не важен; **«ё» = «е»** (`folding(options: [.caseInsensitive, .diacriticInsensitive], locale: ru_RU)` либо явная замена);
- ищем по: названию категории, названию счёта (у перевода — по обоим счетам), тегам, заметке;
- запрос с «#» (`#кофе`) ищет **только по тегам** (подстрока имени тега); так же работает тап по чипу тега в строке ленты — открывает поиск с запросом `#Тег` без клавиатуры (решение владельца 2026-10-12; оставлять ли тап — решит после проверки);

- поиск идёт по всей истории и сочетается с выбранным счётом в карусели (И).

**Выход из поиска:**
- ✕ рядом со строкой → запрос очищается, фокус снимается, всё пружиной возвращается в обычное состояние;
- свайп по ленте вниз прячет клавиатуру (`.scrollDismissesKeyboard(.immediately)`); если запрос **пустой** и фокуса нет — поиск закрывается сам; если запрос есть — режим поиска остаётся (поле без фокуса, тап по нему возвращает клавиатуру);
- открытие шита «+» или редактирования операции режим поиска не сбрасывает; после сохранения результаты пересчитываются.

   - При выбранном «Долги» под каруселью счетов (зазор 8) — **вторая карусель контрагентов**: такие же двухстрочные карточки (метка цвета, имя, долг со знаком и цветом). Тап — лента по этому контрагенту, повторный тап — все долги.
   - **Hero в режиме долгов:** слева «Вам должны» + сумма (34 bold `debtOwedToMe`), справа «Вы должны» + сумма (17 semibold `debtIOwe`) — по всем контрагентам или по выбранному; полосы и легенды нет, тап ничего не делает. Месяц из шапки на hero долгов не влияет (долг — за всё время), лента — как обычно, по месяцу.
   - Пусто: «Операций по долгам нет.» / «По этому контрагенту операций нет.»
4. **Счета (§4.5):** под сноской о счетах — **карточка «Долги»** (`card`, радиус 22, паддинг 16/12): иконка `person.2` в круге `fill` · «Долги» (16 medium) и под ним «Контрагентов: N» (13 `ink2`) · справа итог со знаком и цветом + шеврон. Полный список контрагентов на экран счетов не выводится. Тап → модальный экран «Контрагенты».
5. **Экран «Контрагенты»** (шит, `NavigationStack`, заголовок inline, «Готово» слева, «+» справа):
   - сводка «Вам должны · Вы должны»;
   - список (карточка радиус 22): иконка · имя · долг со знаком и цветом. Тап — изменить (имя, цвет, иконка — форма как у категории); свайп влево — «Удалить» (короткий/длинный, как в ленте); долгое нажатие — меню «Изменить / Удалить»;

   - **удаление мягкое**: контрагент пропадает из каруселей и списков, его операции остаются в ленте и в балансах счетов, в итогах долгов он не учитывается. Если долг не 0 — сначала alert «Удалить «Инга»? Долг +500 ₽ останется в истории операций, но пропадёт из итогов.» · «Удалить» (destructive) / «Отмена».
